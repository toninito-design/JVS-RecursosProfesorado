# JVS Repositorio Docente · Edición compacta Teams

Sube `index.html` a la raíz del repositorio GitHub Pages, sustituyendo la versión anterior. El archivo incluye los logotipos y los 44 enlaces (39 anteriores + 5 nuevos; Control Libro y materiales se añade como enlace adicional aunque coincide en destino con Gestión de libros y material).

Nuevos enlaces: General (Petición de almuerzos, Registro PICS, Control Libro y materiales) y Plataformas docentes (EdPuzzle, MuseScore, Soundtrap).

**Registro PICS**: se ha usado `https://pic.gruposorolla.es/` en lugar de la URL `callback.php?code=...` suministrada, porque esa URL incluye parámetros temporales de autenticación que no deben publicarse en GitHub. Si la dirección base no presenta una pantalla de acceso, sustituye la URL por el enlace estable de inicio de sesión proporcionado por el administrador del servicio.

Diseño de dos columnas, botones compactos, optimizado para espacios estrechos de Teams. Se mantiene almacenamiento local y panel de administración de la versión inicial. Los enlaces agregados al catálogo inicial también se incorporan cuando ya existan datos locales, sin eliminar las personalizaciones previas.

Para que Teams muestre la web, añade como pestaña la URL pública de GitHub Pages. Si Teams restringe la incrustación de GitHub Pages, abre el enlace en el navegador externo o solicita la configuración pertinente al administrador de Teams.
