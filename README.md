# JVS · Repositorio de recursos docentes

Web estática preparada para GitHub Pages.

## Publicar
1. Crea un repositorio en GitHub.
2. Sube `index.html` a la raíz de la rama `main`.
3. En Settings → Pages, selecciona Deploy from a branch → main → /(root).

## Gestión de enlaces
La sección privada permite añadir, editar y eliminar enlaces **solo en el navegador donde se hace el cambio**. El botón Exportar crea `JVS_enlaces.json` para copia de seguridad. La web no puede escribir en GitHub por sí misma. Para publicar modificaciones para todos, habrá que actualizar el catálogo embebido en `index.html` o implementar una base de datos/backend.

## Seguridad
La contraseña solicitada está incluida en el código JavaScript público y **NO constituye protección real**. No guardes credenciales, enlaces secretos ni datos sensibles en este repositorio. Si necesitas una administración privada real y cambios globales, utiliza autenticación y backend.

Canva se muestra como pendiente porque no se proporcionó URL. Algunos enlaces requieren autenticación institucional.
